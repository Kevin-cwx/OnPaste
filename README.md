A productivity tool for pasting images into a browser.

https://onpaste.netlify.app/

## Functionalities
- Zoom
- Copy
- Crop
- Paste
- Download
- Rotate
- Get Color
- Blur
- Focus
- Draw
- side by side image comparison
- Persistent notepad with automatic saving

The notepad text and its open/closed state are saved in your browser's local storage, so they remain available when you return later. The notepad follows the app's light and dark themes.
